# Figmol — конструктор сайтов на канвасе

Figma-подобный редактор: собираешь сайт на свободном канвасе из блоков, по кнопке «Опубликовать» получаешь живой сайт на GitHub Pages, а в своём репозитории — полноценный $mol-проект, который можно развивать дальше руками.

## Зафиксированные продуктовые решения

- **Редактор**: свободный канвас (drag & drop, произвольные позиции) + Auto Layout фреймы как в Фигме. Фрейм = flex-контейнер с direction/gap/padding — маппится 1:1 на `$mol_view`, адаптив получается бесплатно.
- **Экспорт**: полноценный MAM-проект (view.tree + view.ts + view.css.ts). В репо пушатся чистые исходники + `deploy.yml`; GitHub Actions сам собирает через mam и публикует Pages (~2-3 мин).
- **Деплой**: GitHub OAuth App («Sign in with GitHub»), прокси обмена code→token — node-эндпоинт в докере на VPS 87.120. Создание репо, пуш файлов, включение Pages — через REST API прямо из браузера, токен только у клиента.
- **Хранение проектов**: Giper Baza — local-first, синк между устройствами, шаринг по ссылке, потенциально совместное редактирование.
- **Набор блоков**: примитивы (текст, картинка, кнопка, прямоугольник, фрейм) + компоненты `bog/builderui` (card, tabs, gallery, menu…) + готовые секции-шаблоны (hero, фичи-грид, футер).
- **Мультистраничность**: сразу — список страниц, навигация, роутинг в экспорте.

## Архитектура модуля

```
bog/figmol/
  schema/    — Giper Baza entities: Site, Page, Node
  app/       — редактор: Canvas, Toolbar, Layers, Inspector, Pages
  blocks/    — реестр блоков: примитивы, builderui-обёртки, секции
  gen/       — генератор: дерево нод → view.tree / view.ts / css.ts
  deploy/    — GitHub-клиент: OAuth, создание репо, пуш, Pages
  server/    — OAuth-прокси (node, докер на 87.120)
```

## Модель данных (Giper Baza)

- `figmol_site` — title, список страниц, настройки темы (токены builderui)
- `figmol_page` — title, slug, корневая нода
- `figmol_node` — kind (`text|image|button|rect|frame|bui_*|section_*`), props (словарь),
  геометрия x/y/w/h, layout для фреймов (direction, gap, padding, align),
  children (упорядоченный список нод)

## Этапы

1. **Каркас + канвас-ядро** — модуль (scaffold через `npm create view-tree-lsp`), схема Базы, канвас с pan/zoom, тулбар примитивов, добавление/drag/resize/selection, автосохранение в Базу.
2. **Auto Layout + инспектор** — фреймы (direction/gap/padding/align), панель свойств справа, inline-редактирование текста, цвета и шрифты из токенов builderui.
3. **Страницы + блоки** — панель страниц, builderui-компоненты на канвасе, секции-шаблоны, панель слоёв.
4. **Генератор кода** — дерево нод → MAM-модуль, превью собранного сайта в редакторе.
5. **Публикация** — OAuth-прокси на VPS, кнопка «Опубликовать»: создать репо → пуш исходников + deploy.yml → включить Pages → показать статус и ссылку.
6. **Шаринг и полировка** — шаринг проекта по ссылке, совместное редактирование, undo, хоткеи.
